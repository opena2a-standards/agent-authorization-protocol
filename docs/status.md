# Status

The last released versions are `0.5.1-draft` of `AAP-SPEC.md` and `0.4.1-draft` of the companion
`AAP-BROKER-PROFILE.md`. Authored in the open as an IETF Internet-Draft:
`draft-fane-opena2a-aap-02` (the 0.5.1-draft text, submitted 2026-10-02) is the current revision
on the [datatracker](https://datatracker.ietf.org/doc/draft-fane-opena2a-aap/); its source and
rendered text are in this repository. The next revision, `draft-fane-opena2a-aap-03`, is in this
repository as source and rendered text and is not submitted. Each document carries its own
version at the top. Between releases the text on main moves ahead of that version and of the
submitted revision, and the version line says so ("plus unreleased changes"); the [Unreleased]
section of `CHANGELOG.md` lists those changes. `CHANGELOG.md` also records what moved between
drafts and which draft revision pairs with which version.
